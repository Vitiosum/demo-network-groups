        Traffic between members travels in WireGuard tunnels across Clever Cloud’s network: keys exchanged with Curve25519, packets sealed with ChaCha20-Poly1305. Clever generates the configuration when the group is created. The apps only see a private interface and a DNS name, and any port of a member is reachable inside the group.

        Request path, last trip

        1. Lobby resolves the vault’s member name–DNS
        2. Request and answer cross the WireGuard tunnel–HTTP over the Network Group
        3. Vault checks the caller is a peer, then answers–inside the vault app
